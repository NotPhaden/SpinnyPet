# V22.6.2 Color Dice Fix

- Live Color Dice now updates without a manual page refresh.
- A creator's open Color Dice match is restored after page refresh, including the Cancel action.
- The creator's own open match is shown inside **Live Color Dice**.
- Joiners cannot select either color already chosen by the host; the UI marks those colors as **Taken** and the database rejects them too.
- Color Dice remains a **single final color roll**: each player owns two possible winning colors, and the server rolls colors until it lands on a color belonging to exactly one side.
