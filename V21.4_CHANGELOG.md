# SpinnyPet V21.4.1

## Hard fixes requested after V21.3

- Color Dice match result no longer uses the broken spinning color wheel/background artifact. The match now shows a transparent 3D-style die with the six-color selection system preserved.
- Color Dice keeps the 3-second server-result countdown, reveal, sounds, Close button and automatic close.
- Case Battle now uses the **same full-size Cases opening reel**: case art, central marker, 67-item reel, 4.6s opening animation, pet reveal and synchronized Player 1 / Player 2 POV. Cases open one-by-one before the final winner.
- Case Battle has explicit Close + automatic close after the final result.
- Sidebar route fixed: **Time Rewards** now actually renders the Time Rewards page instead of an empty page.
- Time Rewards shows the five case stages with visible case art and automatic ticket unlocks.
- Giveaways JOINED state no longer gets cleared by a failed/missing server RPC. Local JOINED state is retained and merged with server state.
- Chat giveaway carousel now preserves the selected giveaway by ID across refreshes, so the JOINED state stays on the giveaway you joined.
- Clans now use a more PS99-style hierarchy: My Clan / Top Clans, battle rewards header, clan profile, members + points, diamond treasury, Deposit Diamonds, leader-only treasury upgrades, and Top Clans points/diamonds.
- Added `beta_get_top_clans()` RPC so Top Clans does not depend on direct table RLS reads.
- Clan upgrades consume only treasury diamonds; personal diamonds are consumed only by Deposit.
