# V22.7 Super Update

## Gameplay fixes
- Fixed the `beta_inventory_quantity_check` failure when Coinflip pet stacks are fully consumed.
- Standardized safe inventory consumption so a pet stack is deleted when exhausted and never temporarily written as quantity `0`.
- Case Battle now supports the same 1–50 round range exposed by the UI.
- Case Battle cost validation now counts duplicate cases correctly.
- Case Battle records create/result activity more consistently.

## Inventory
- Added **Sell Pet** for an individual stack.
- Added **Sell Selected** for multiple selected stacks.
- Added **Sell All** for all pets with a valid PS99 RAP value.
- Diamond payout is based on stored PS99 RAP × quantity.

## Admin / live FX
- Added realtime **Admin Abuse / Chaos Console**.
- Page-targeted effects: Home, Coinflip, Color Dice, Inventory, Profile, Time Rewards, Cases, Case Battle, Leaderboard, Clans, Giveaways, Promo and Admin.
- Added animated Jackpot Rain, Coin Storm, Dicefall, Pet Swarm, Case Burst, Reality Glitch and Rainbow Override effects.
- Optional server-side diamond reward can be granted to every account and is recorded in activity history.
